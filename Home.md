## Workflow

1. Capture thoughts immediately in `00-inbox`.
2. Review and organize notes when convenient.
3. Document useful technical work in the relevant project.
4. Commit meaningful changes to Git.

## Principles

**Capture first. Organize later.**

Markdown is the source of truth. Git provides version history. Obsidian provides navigation and editing.
